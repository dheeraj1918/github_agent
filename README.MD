🤖 GitHub Agent

## 📌 About

**GitHub Agent** is an AI-powered tool that automatically generates detailed `README.md` files and provides insights into GitHub repositories and developer profiles. 

By analyzing project structures, programming languages, package files, and commit histories, this tool creates professional documentation effortlessly using LLM capabilities.

---

## ⚙️ Virtual Environment Setup (`.venv`)

It is recommended to run this project inside a Python virtual environment (`.venv`).

### 1. Create `.venv`

```bash
python -m venv .venv
```

### 2. Activate `.venv`

- **On Windows (Command Prompt):**
  ```cmd
  .venv\Scripts\activate
  ```

- **On Windows (PowerShell):**
  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- **On macOS / Linux:**
  ```bash
  source .venv/bin/activate
  ```

## 🚀 How to Run This Code

### 1. Clone the Repository
```bash
git clone https://github.com/dheeraj1918/github_agent.git
cd github_agent
```

### 2. Activate Virtual Environment
*(Follow the `.venv` activation step above)*

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Set Up Environment Variables
Create a `.env` file in the project root directory and add your API credentials:

```env
gemini_api=<API_KEY>
```

### 5. Run the Script

- **Generate a README for a repository:**
  ```bash
  python main.py --repo dheeraj1918/github_agent
  ```
**This README file is generated by this repo agent. **
```
